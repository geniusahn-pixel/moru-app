# 📚 모루 독서 기록장

독서모임을 위한 독서 기록장 웹앱입니다. 책을 등록해 독서 과정을 기록하고,
모임 일정과 모임별 책을 관리하며, 별점·한줄평·토론 메모를 남기고,
연간 목표와 통계를 한눈에 볼 수 있습니다.

## 주요 기능

- **홈 (통계·목표)** — 총 완독/읽는 중/평균 별점 요약, 연간 목표 달성률(도넛),
  월별 완독 막대그래프, 최근 완독한 책
- **큰글씨(키오스크) 모드** — 헤더의 `🔍 큰글씨` 버튼으로 전환하는 고령층 친화 화면.
  큰 글씨·큰 버튼·고대비로, 오늘의 인사, 목표 달성률, 큰 숫자 요약(다 읽은 책/읽는 중/
  다가올 모임), 지금 읽는 책(진행률), 다음 모임(D-day), 큰 메뉴만 단순하게 보여줍니다.
  전환 상태는 브라우저에 기억됩니다(도서관·경로당 등 공용 태블릿 키오스크 배치용).
- **내 서재 (책 등록·독서 기록)** — 책 추가, 상태(읽고 싶어요/읽는 중/다 읽음),
  진행률(현재 쪽/전체 쪽), 시작·완독일, 별점, 한줄평, 감상 메모, 토론 발제 메모
- **모임 (일정·모임별 책)** — 회차/날짜/장소, 이번 모임 책 연결, D-day,
  다가오는 모임과 지난 모임 구분, 모임 메모

## 실행 방법

```bash
npm install      # 최초 1회
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 배포용 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

## 기술 스택

- React 18 + Vite
- 저장소: 브라우저 `localStorage` (백엔드 없이 동작)

## 데이터 저장 안내

현재 모든 기록은 **사용하는 브라우저에만** 저장됩니다(`localStorage`, 키: `moru.data.v1`).
따라서 기기/브라우저가 바뀌면 데이터가 공유되지 않습니다.

모임원들이 기록을 함께 보고 공유하려면 서버(로그인 + DB)가 필요합니다.
데이터 접근 로직은 `src/store.js`의 `loadData`/`saveData` 한 곳에 모아 두었으므로,
이 두 함수를 API 호출로 바꾸면 화면 코드 수정 없이 서버 연동으로 확장할 수 있습니다.

```

  util.js             날짜/진행률 등 유틸
  index.css           테마(라이트/다크) 스타일
  components/
    Stars.jsx         별점
    Sheet.jsx         하단 시트 모달
  views/
    Dashboard.jsx     홈(통계·목표)

    Books.jsx         내 서재(책·독서기록·별점·메모)
    Meetings.jsx      모임(일정·모임별 책)
```
